data(mtcars)
summarise_cols <- function(df, column) {
  if (!(column %in% names(df))) {
    print("The column name isnt present")
  }
  if (!is.numeric(df[[column]])) {
    print("The column isnt numeric")
  }
}

  
summarise_cols(mtcars, "mpg")
summarise_cols(mtcars, "hp")
summarise_cols(mtcars, "wt")

Using [[ is safer than $ in functions because $ expects the literal column name from the data set. However, [[ is more flexible so it better to use in functions.
